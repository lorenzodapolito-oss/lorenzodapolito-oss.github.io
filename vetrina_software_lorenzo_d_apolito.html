1. Cartella /screenshots

Aggiungi le immagini reali

Crea una cartella chiamata screenshots/ accanto a index.html e salva gli screenshot (es. docplane.png). Poi inserisci il percorso nel campo screenshot dell'app.

2. GitHub Releases

Link di download già pronti

Tutti i pulsanti Scarica puntano già alla pagina /releases di ciascuno dei tuoi 19 repository su github.com/lorenzodapolito-oss. Ti basta caricare gli eseguibili compilati in Rust nelle Releases.

3. Attiva GitHub Pages

Metti il sito online gratis

Crea un repository chiamato lorenzodapolito-oss.github.io, carica index.html e la cartella screenshots/, quindi attiva Pages da Settings → Pages.
